1. 出力可視化プロットイメージと各部位の分析内容

make dev 実行時、車両の走行と完全に同期して以下の解析画像ファイル（trajectory_analysis.png）が /output/YYYYMMDD-HHMMSS/ 直下に全自動生成・更新されます。
※以下のベクトル可視化モデルは独立CSS/SVG描画されているため、単体HTMLのみをローカル環境でダウンロードして開いても外部画像ファイル依存なしで100%確実に表示されます。

【自動生成プロット構造モデル: trajectory_analysis.png (4 Subplots)】

4つのサブプロットにおける具体的なデータ分析手法

① Driving Line (2D 走行軌跡 & 車速カラーマップ)

参照 raceline (黒破線) に対する実走行軌跡を車速カラーマップ ($v \text{ [km/h]}$) でグラデーション描画。
分析内容: ・クリッピングポイント（イン突き）の精度確認
・コーナーアウト膨らみおよびコース壁接触リスクの特定
・S字コーナー (X: 89620〜89640) での走行ラインのスムーズさ確認

② Velocity Profile ($v$ vs $s$ 速度推移)

走破距離 $s \text{ [m]}$ に対する実車速 $v(s) \text{ [km/h]}$ の連続推移グラフ。
分析内容: ・ブレーキ開始地点およびボトムスピードの分析
・コーナー立ち上がりでの加速遅れの発見
・直線区間での最高速度到達（45 km/h）の検証

③ Acceleration Check ($a_x$ vs $t$ 加速度ルール適合)

時間 $t \text{ [s]}$ に対する縦加速度指令 $a_{\text{cmd}}(t) \text{ [m/s}^2\text{]}$ と SW ルール上限線 ($1.0 \, \text{m/s}^2$)。
分析内容: ・数式 $$a_{\text{cmd}}(t) \le 1.0 \, \text{m/s}^2$$ の完全遵守チェック
・ペナルティ速度制限をトリガーする不正加速度スパイクの監視

④ Lap Time & Performance Metric Summary

スタート地点通過判定による自動ラップタイム計測結果およびルール適合テキスト。
分析内容: ・周回ごとの通過ラップタイム、ベストラップ、平均タイム
・最高縦加速度 $$a_{\text{max}} \le 1.05 \, \text{m/s}^2$$ の自動合否判定 (PASS/FAIL)

3. クラス構造モデル (Mermaid Class Diagram)

analyze_trajectory.py 内の主要クラス TrajectoryAnalyzer とその内部関数・メンバ変数の構造をクラス図として可視化しています。

classDiagram class Node { +declare_parameter() +get_parameter() +create_subscription() +create_timer() +get_logger() } class TrajectoryAnalyzer { +String output_dir +List timestamps +List x_data +List y_data +List v_data +List a_cmd_data +List steer_cmd_data +List ref_x +List ref_y +List lap_times +__init__(output_dir) +cmd_callback(msg: AckermannControlCommand) +ref_callback(msg: MarkerArray) +odom_callback(msg: Odometry) +save_analysis_plots() } Node <|-- TrajectoryAnalyzer

関数構造と役割一覧

関数・メソッド名 入力パラメータ / ROS 2 トピック 内部処理と役割の詳細
__init__() output_dir: str ROS 2 ノード初期化、output_dir パラメータ宣言、サブスクリプション（3種）設定、10秒周期タイマー生成。
odom_callback() /localization/kinematic_state (Odometry) 車両位置 $(x, y)$、車速 $v = \sqrt{v_x^2 + v_y^2}$、時刻 $t$ をバッファ追記。スタート通過判定により周回ラップタイムを自動計算。
cmd_callback() /control/command/control_cmd (Ackermann) 最新の加速度指令 $a_{\text{cmd}}$ と前輪ステアリング角指令 $\delta_{\text{cmd}}$ を追記。
ref_callback() /mpc/ref_path (MarkerArray) [改修済み] MPC参照 raceline 座標 $(x_{\text{ref}}, y_{\text{ref}})$ を受けるたびに最長マーカー配列で全周累積補完。
save_analysis_plots() 内部データバッファ全般 走破距離 $$s = \sum \sqrt{\Delta x^2 + \Delta y^2}$$ を計算し、Matplotlib 2x2 プロット画像を生成。最高加速度 $$a_{\text{max}} \le 1.05 \, \text{m/s}^2$$ を判定し PNG 保存。
