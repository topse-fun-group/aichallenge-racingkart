# ADR-006: FollowState コーナー壁衝突防止 & 追突防止 (Corner Tracking & Rear-End Collision Prevention)

## ステータス
承認済み (Accepted)

## コンテキスト
`FollowState`（先行車追従 MPC 制御）において以下の 2 つの重大な問題が観測された：
1. **コーナーで壁に衝突する**: カーブを曲がる際に MPC がステアリング角を出し渋り、アンダーステアで壁に突入。
2. **前走車への追突が依然として発生する**: 車間距離 3m が短すぎ、制御遅延により追突。

### 根本原因の分析

#### 致命的バグ: `_apply_state_params` で `update_R()` が欠落
`mpc_controller.py` の `_apply_state_params` メソッドにおいて、Q マトリクスと QN マトリクスは `self._mpc.update_Q()` / `self._mpc.update_QN()` で MPC ソルバーに反映されていたが、**R マトリクスは `self._mpc_cfg.R` に保存するだけで `self._mpc.update_R()` を呼んでおらず、ソルバーに一切伝わっていなかった**。

#### MPC パラメータの不適切な設定
| パラメータ | FollowPathState | FollowState (修正前) | 影響 |
|:---|:---|:---|:---|
| R[1] (ステアリングコスト) | **100** | **1,000** (10倍) | ステアリング操作を過度に抑制 → コーナーで壁衝突 |
| Q[2] (速度追従重み) | **850,000** | **200,000** (1/4) | 目標速度への追従が弱い → 減速指令に反応しない → 追突 |
| Q[0] (横偏差重み) | **1,000,000** | **5,000,000** (5倍) | 横偏差許容が狭すぎる → コーナーで無理な軌道を取る |

#### 車間距離 3.0m が遅延に対して不十分
V2X 位置情報の遅延、MPC ソルバー計算遅延、ローパスフィルタ遅延を考慮すると、3.0m では安全マージンが不足。

## 決定事項

### 1. `update_R()` バグ修正
`_apply_state_params` に `self._mpc.update_R(self._mpc_cfg.R)` を追加し、状態遷移時に R マトリクスが MPC ソルバーに確実に反映されるようにした。

### 2. FollowState の MPC パラメータを FollowPathState と同等に最適化
- Q = [1,000,000, 100,000,000, 850,000] — FollowPathState と同一
- R = [100,000, **100**] — FollowPathState と同一（ステアリング操作の自由度を確保）
- QN = [1,000,000, 1,000, 10,000] — 変更なし

### 3. 目標車間距離の拡大
- `TARGET_FOLLOWING_DISTANCE` = **8.0m**（3.0m → 8.0m）
- `STOP_DISTANCE` = **4.0m**（1.8m → 4.0m）
- 制御遅延を吸収する十分な安全マージンを確保。

### 4. FollowState 時の加速度クランプ
FollowState 実行中は正の加速度を最大 **1.0 m/s²**（通常の半分）に制限し、遅延があっても急加速による追突を物理的に阻止。

## 影響と効果
- FollowState でもコーナー旋回能力が FollowPathState と同等に確保され、壁衝突が解消される。
- 8m の車間距離と加速度クランプにより、制御遅延があっても前走車への追突が防止される。
- 先行車が停止から動き出した際も、加速度上限 1.0 m/s² で緩やかに追従するため安全。
