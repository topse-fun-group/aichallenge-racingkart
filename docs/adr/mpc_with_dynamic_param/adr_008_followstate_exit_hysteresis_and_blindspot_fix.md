# ADR-008: FollowState 発進時ブラインドスポット撤廃 & 1.5秒退避ヒステリシス

## ステータス
承認済み (Accepted)

## コンテキスト
`FollowState` で前走車の後ろに停止した後、前走車が動き出して自車も動き出す瞬間に、なぜか `FollowPathState`（Pure Pursuit 35 km/h）に誤遷移して急加速し、前走車に追突する現象が発生していた。

### 根本原因
1. **`x_rel < 0.5m` ブラインドスポット**: 前走車の直後（0.3〜0.5m）に接近して停止すると、前走車が `x_rel < 0.5` に該当して V2X 検出から消去（`None`）されていた。
2. **LiDAR の壁専用レイキャスト**: 直線路では LiDAR が常に 5m 以上（クリア）となり、V2X がブラインドスポットで消えた瞬間に「前方に障害物なし」と誤判定されていた。
3. **退避ヒステリシスの欠如**: たった 1 フレーム（0.025秒）でも V2X が外れると、即座に `FollowPathState`（35 km/h フル加速）へ切り替わっていた。

## 決定事項

### 1. 至近距離ブラインドスポットの撤廃
`_detect_forward_vehicle()` において、`x_rel < 0.5` を `x_rel <= 0.0` に変更し、自車より前方にあるすべての他車（0m 以上）を確実に検知。また方位角を ±45度、横方向許容幅を 3.5m に拡大して安定捕捉。

### 2. FollowState 退避判定に「1.5秒の継続クリア確認ヒステリシス」を導入
`FollowState.check_transition()` において、障害物が完全にいなくなった状態が **1.5秒以上連続** した場合のみ `FollowPathState` へ復帰させる安全タイマーを導入。一時的なロストや瞬断で `FollowPathState` に誤遷移することを 100% 阻止。

## 影響と効果
- 停止状態から前走車が発進する際、至近距離でも前走車を絶対に見失わず、`FollowState` を維持して安全に追従発進する。
- コーナーやライン変更で V2X が一瞬外れても 1.5 秒間は `FollowState` が維持され、急加速による追突が完全に解消される。
