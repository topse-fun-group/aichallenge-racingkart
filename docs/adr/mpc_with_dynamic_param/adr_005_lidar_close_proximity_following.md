# ADR-005: 至近距離LiDARフュージョンと3m相対距離保持制御 (LiDAR Close-Proximity Fusion & 3m Distance Maintenance)

## ステータス
承認待ち (Proposed)

## コンテキスト
V2X 単独での前方車両判定では、V2X 情報のタイムラグやフィルタ除外時に直前の車両を捕捉できず、先行車の直後で追従・停止する際に追突するケースが観測された。
また、ユーザーより「LiDAR の値も使い、半径 3m 以内に他の車両がある場合に確実に相対距離を保つ」仕様が求められた。

## 決定事項

### 1. 3.5m ゲート付き LiDAR 近接フュージョン
LiDAR の前方クリアランスを全距離で使うと遠方のコース壁を誤検知するため、**「3.5m 以下の至近距離に限定して LiDAR を有効化する」ハイブリッド方式**を採用する：
- 距離 $> 3.5\text{m}$: 遠方壁誤検知を防ぐため V2X 車両情報のみを採用。
- 距離 $\le 3.5\text{m}$: LiDAR 実測クリアランスを即時採用し、V2X の有無に関わらず直前の先行車・障害物に対して確実に車間保持・停止を発動。

### 2. 半径 3m 相対距離保持制御 (3m Relative Distance Control)
`FollowState` の追従目標車間距離を $3.0\text{m}$ に設定し、以下の 3 段階ガバナー制御を実施：
- $d \le 1.8\text{m}$: 目標速度 $0.0\text{ km/h}$ & ブレーキ指令（安全マージンを保ち完全停止）
- $1.8\text{m} < d < 3.0\text{m}$: $v_{\text{target}} \le v_{\text{leader}} \times \left(\frac{d - 1.8}{1.2}\right)$（先行車速度以下でゆっくり車間を 3m に回復）
- $d \ge 3.0\text{m}$: $v_{\text{target}} = v_{\text{leader}} + K_p (d - 3.0)$（3m の相対距離をキープして巡航）

### 3. `FollowPathState`（Pure Pursuit）からの即時退避
Pure Pursuit 走行中であっても、LiDAR または V2X が 3.5m 以内に物体を検知した場合は直ちに `FollowState` に遷移させ、Pure Pursuit の高速巡航による追突を未然に防止する。

## 影響と効果
- 遠方コース壁による `FollowState` 誤遷移を防ぎつつ、3m 以内に先行車が存在する場合は 100% 確実に距離を検知して停止・車間保持を行う。
- 先行車が停止した場合は 1.8m〜3.0m の安全な相対距離で確実に停止し、先行車が発進すれば 3.0m の車間を保って追従する。
