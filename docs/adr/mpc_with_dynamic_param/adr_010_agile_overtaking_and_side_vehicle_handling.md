# ADR-010: 俊敏な追い越しステアリング強化 & 並走車両減速回避制御

## ステータス
承認済み (Accepted)

## コンテキスト
1. **追い越し時の衝突リスク**:
   `OvertakeState` への遷移後、横オフセット補間レートが `rate = 0.08` と緩やかであり、ステアリングローパスフィルタも `steer_low_pass_gain = 0.40` であったため、目標オフセット（1.5m）に到達するまでに約 0.7 秒（走行距離約 6m）かかり、横へ避ける前に前走車に接触・追突する事象が発生していた。
2. **横並び（サイドバイサイド）車両への対応**:
   自車の真横（$-2.5\text{m} \le x_{\text{rel}} \le 2.5\text{m}$）に他車がいる場合、前方車両として検知されず、道幅が狭い場合でも無理に並走して接触するリスクがあった。

## 決定事項

### 1. 追い越し動作の俊敏化（Agile Steering & Fast Offset Shift）
- `OvertakeState` 実行時の横オフセット補間レートを `rate = 0.22` に加速し、0.2 秒前後で目標回避ラインへ移行。
- `OvertakeState` 実行時のステアリングローパスフィルタゲインを `0.85` に引き上げ、MPC からのステアリング回避指令を即座に大舵角として出力。

### 2. 横並び車両（Side Vehicle）検知と減速車間確保
- `_detect_forward_and_side_vehicles()` において、$-2.5\text{m} \le x_{\text{rel}} \le 2.5\text{m}$ かつ $0.6\text{m} \le |y_{\text{rel}}| \le 3.5\text{m}$ の範囲に存在する並走他車を検出。
- **道幅が十分（$\ge 1.6\text{m}$）な場合**: そのまま `OvertakeState` へ遷移し、空いている中央ラインを通ってスムーズに追い越し・加速。
- **道幅が不足（$< 1.6\text{m}$）な場合**: `FollowState` において自車目標速度を並走車より $1.5\text{ m/s}$（約 $5.4\text{ km/h}$）低く抑制（減速）し、相手を先に行かせて前後の安全車間距離を速やかに再確保。

## 影響と効果
- 追い越し時に瞬時にステアリングを切って横へ回避できるようになり、前走車への追突が劇的に防止される。
- コーナーや狭い区間で横に他車が並んだ場合でも、安全に減速して前後にスペースを空け、接触事故を確実に防ぐ。
