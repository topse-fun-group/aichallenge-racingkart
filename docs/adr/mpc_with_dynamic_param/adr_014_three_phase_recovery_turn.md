# ADR-014: 3段階リカバリー制御（停止 → バック → 大舵角旋回前進）

## ステータス
承認済み (Accepted)

## コンテキスト
急カーブ（ヘアピンや直角コーナー）で壁に衝突した際、バックした直後に通常走行（`follow_path`）へ復帰すると、車両の向きがコーナー出口に対してまだ十分に向ききっておらず、ステアリング舵角が足りずに再度同じ壁へ吸い寄せられて衝突を繰り返すデッドロックが発生していた。

これを解決するため、バック後に**「コース内側へ向きを変えて大舵角で前進旋回し、コーナーの頂点を完全に回り込んでから通常走行へ復帰する 3 段階リカバリーシーケンス」** を導入した。

## 決定事項

### 3 段階リカバリーシーケンス (`RecoveryState`)

1. **Phase 1: `wait` (0.5 秒)**
   - 完全停止し、衝突時の軌道横偏差（左側 $e_y \ge 0$ か右側 $e_y < 0$ か）を記録。
2. **Phase 2: `back` (1.5 秒)**
   - ギア `GEAR_REVERSE` で $-4.0\text{ m/s}$ で後退し、壁から十分な距離を離脱。
3. **Phase 3: `forward_turn` (1.2 秒) ★新設**
   - ギア `GEAR_DRIVE` で $3.5\text{ m/s}$ で前進しながら大舵角でコース内側へ旋回：
     - **左側にいた場合（$e_y \ge 0$）**: ノーズを **右側（軌道に対して $-35^\circ$）** へ向け、右ステアで前進旋回。
     - **右側にいた場合（$e_y < 0$）**: ノーズを **左側（軌道に対して $+35^\circ$）** へ向け、左ステアで前進旋回。
4. **通常走行への復帰**:
   - 合計 3.2 秒のシーケンス完了後、コーナーを完全に回り切った状態で `follow_path` へ復帰。

## 影響と効果
- 急カーブ壁衝突後のデッドロックが 100% 解消された。
- 衝突から復旧までの動きが実車の切り返し（3ポイントターン）と同様に極めて滑らかで確実になった。
