# ADR-050: 中断直後の再突入では寄せ側を引き継ぐ（蛇行の停止）

## ステータス
**撤回 (Superseded by ADR-053)**

40 周の同条件 A/B (v1.3.6 = 20260831-163410 / 本 ADR 込み = 20260831-155636) で
全項目が退行した。衝突 34 -> 44、試行 393 -> 346、成功 144 -> 132、recovery 11 -> 22。
狙いだった側の反転は対象母集団で 60% -> 56% しか動かず (門番の
>= OVERTAKE_HARD_ABORT_WIDTH_M が、幅で降りた側 = 対象の 75% をまさに弾くため)、
発火した 9 件は反対側に 4.17m あるのに 1.81m の側へ突入させて全件失敗した。
単一走行の相関から因果を立てたのが誤りだった。

`OvertakeState.on_enter` が毎回 `resolve_overtake_side` を引き直すのをやめ、
中断直後の再突入では前回の側を引き継ぐ。**突入条件と中断条件は変更しない。**

## コンテキスト

`output/20260831-120626`（rosbag 付き・2553 s・追い越し 549 件・成功 196 = 36%）を
ADR-049 の診断項目つきで解析した。**低速時間は 261 s = 10%**
（本番 v1.3.6 は 19%、v1.3.4 は 46%）。報告された 4 点を切り分けた。

### 決着: 寄せ側が短時間で反転し、コースを横切って蛇行している

```text
連続する追い越し突入 546 組
  寄せ側が反転した            294 組 (54%)
  うち 3 秒以内の反転          82 組 (15%)
  突入間隔 中央 3.25s

追い越しの離脱 -> 再突入 475 組
  中央 1.90s、2 秒以内の再突入 241 件 (51%)、うち側が反転 138 件
```

`overtake` から `recovery` に落ちた 5 件のうち **4 件で `d_off` と `e_y` の符号が逆**。

```text
d_off=-1.82 (右へ指令)  e_y=+1.85 (実際は左に 1.85m)  lw=0.59 (左は狭い)
d_off=-1.20             e_y=+2.60                    lw=0.59
d_off=-1.48             e_y=+2.45                    lw=1.84
d_off=-1.98             e_y=+1.58                    lw=1.01
```

**狭い左側へ 1.6〜2.6 m 出た状態で「右へ戻れ」と指令されている。**
側を反転した直後、コースを横切っている最中に壁または前車へ当たっている。

`OVERTAKE_COMMIT_SEC = 1.5` は突入**後**の維持時間で、**再突入時の側は縛らない。**
中断直後は寄せていた側の幅が崩れているので、反対側が「広い側」に見えて反転する。

### 報告された 4 点の切り分け

| 報告 | 判定 |
|---|---|
| ① 前の車と衝突が増えた気がする | 上記の蛇行で説明がつく。`overtake -> recovery` は 549 件中 5 件（0.9%）と低い |
| ② 中央付近の停止車に突っ込む | **解消済み**（下表）。今回は触らない |
| ③ 最後から 3 番目のコーナーで無理な追い越し | s=280〜345 m。`follow->overtake` 31 回 / `overtake->follow` 22 回とチャーンが最も激しく、低速時間の 43%（112.5 s）を占める。同一原因 |
| ④ 開始位置付近で瞬間的に左へ寄って壁に衝突 | 上記の符号逆転そのもの |

```text
先行車の速度別      n    成功        幅中断
停止 (<2km/h)       4    3 (75%)      0%
2-10 km/h           7    4 (57%)     29%
20+ km/h          529  189 (36%)     48%
```

v1.3.5 run2 の「停止車の前で 190 s 空費」は再現していない（ADR-039 / ADR-045 が効いている）。

### 併せて確定した P0'（横に出られない）の答え

ADR-049 の診断で決着した。**操舵は追従できている。**

```text
d_off と e_y の符号一致 94%、一致時の追従誤差 中央 0.73 m
w (先読み点の Hann 重み) 中央 0.81、0.5 未満は 5%
```

問題は**指令側**。突入時の側幅は 3.15 m（式 `(w-0.5)/2+0.895` なら 2.22 m）なのに、
実際に狙う `d_off` は **中央 1.04 m**。壁クランプ
`clip(target_offset, lb+1.225, ub-1.225)` が**先読み点の waypoint 境界**で効いている。
**判断は先行車位置の幅、操舵は先読み点の幅**と、別の場所の幅を見ている。

ただし「突入時の `side_w` で門番する」案は 549 件中 **3 件**しか変わらず、
成功率も帯間で平坦（`side_w` 2.6-3.2 で 37%、3.2 以上で 34%）だった。
**有効な修正が見えていないので今回は記録に留める。**

## 決定事項

### 中断直後の再突入では前回の寄せ側を引き継ぐ

```python
OVERTAKE_SIDE_HOLD_SEC = 2.5   # [s]

    # on_exit
    self._last_side = self._overtake_side
    self._last_exit_time = ctx.current_time_sec

    # on_enter
    side = resolve_overtake_side(ctx)
    if (self._last_side in ("left", "right")
            and (ctx.current_time_sec - self._last_exit_time) < OVERTAKE_SIDE_HOLD_SEC
            and overtake_width_of(ctx, self._last_side) >= OVERTAKE_HARD_ABORT_WIDTH_M):
        side = self._last_side
    self._overtake_side = side
```

- **試行回数は減らない。** 突入を止めるのではなく側を固定するだけ（ADR-040 の教訓）
- 前回側が物理的下限（`OVERTAKE_HARD_ABORT_WIDTH_M = 1.5 m`、ADR-044）を割っていれば
  引き継がず通常どおり引き直す
- 2.5 s 以上空いた再突入は従来どおり

`overtake_width_of` と `OVERTAKE_HARD_ABORT_WIDTH_M` は既存。新規定数は 1 つだけ。
`STATE_PARAM_MAP` に `overtake_side_hold_sec` を追加。

## 未解決事項

1. **`d_off` がコリドーの想定の半分に潰れている。** 判断（先行車位置の幅）と
   操舵（先読み点の幅）で別の waypoint を見ている。`side_w` での門番は効かないと
   確認済み（549 件中 3 件）。有効な案が無いので保留。
2. 横シフトの起点が自車基準（ADR-045 未解決事項 2）。
3. 実測ヨーレートが指令からの期待値の 0.39 倍。二段ゲイン
   （`steering_tire_angle_gain: 1.5` と `steering_tire_angle_gain_var: 1.639`）が
   意図どおりか未確認。
4. ADR-042〜050 はいずれも本番未検証（ADR-049 まで投入済み、050 は今回）。

## 検証

`test/test_overtake_corner.py` に 6 件追加。**160 件パス。**

| ケース | 期待 |
|---|---|
| **離脱直後（< 2.5 s）の再突入** | **前回の側を維持する**（本命） |
| 2.5 s 以上経過した再突入 | 通常どおり `resolve_overtake_side` で引き直す |
| 前回側が物理的下限未満 | 引き継がず引き直す |
| 前回側がちょうど下限 | 引き継ぐ |
| 初回の突入（前回側なし） | 通常どおり |
| `OVERTAKE_SIDE_HOLD_SEC` を 0 に | 引き継ぎ無効（呼び出し時に読む） |

実走は **`make dev3-rosbag`** で行う。今回の切り分けは診断項目と rosbag の
両方が揃って初めて可能だった。

| 指標 | 20260831-120626 | 期待 |
|---|---|---|
| **連続突入での側の反転** | **294 / 546 (54%)** | **大きく減る（本命）** |
| 2 秒以内の再突入での側反転 | 138 件 | ほぼ 0 |
| `overtake` からの recovery | 5 件 | 減る |
| 離脱時に `d_off` と `e_y` が逆符号 | 5 件中 4 件 | 減る |
| **試行回数** | **549** | **維持** |
| 成功件数 | 196 (36%) | 維持〜増 |
| 低速時間 | 261 s (10%) | 維持〜減 |
| s=280-345 のチャーン | `follow->overtake` 31 / `overtake->follow` 22 | 減る |

**主なリスク**: 前回側を引き継いだ結果、実際には反対側の方が広い場面で不利な側を
走ること。物理的下限を割れば引き継がないので致命的にはならないが、成功件数が
落ちていないかを確認する。落ちていれば `OVERTAKE_SIDE_HOLD_SEC` を 1.5 s 前後へ
短縮するのが最初の調整点。
