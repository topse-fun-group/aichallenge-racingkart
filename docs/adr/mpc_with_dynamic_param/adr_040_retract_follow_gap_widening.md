# ADR-040: 追従車間の拡大を撤回する（成功「率」で評価した誤り）

## ステータス
承認済み (Accepted)

**ADR-037 の決定 1（目標車間の速度依存化）を撤回する。**
決定 2（停止距離を通常の追従経路に入れる）は**維持**する。
ADR-039（ADR-038 の撤回、停止車の veto 例外）は維持する。

## コンテキスト

ADR-037 を「追い越しへの副作用が無い」と評価したが、**これは誤りだった。**
成功「率」だけを見て成功「件数」と試行回数を見ていなかった。

```text
走行                        試行   成功件数  成功率   直線成功   follow遷移
ADR-036 まで (内側veto)     370     139     38%       27        357
+ADR-037 (h=0.25)          226     103     46%       10        219
+ADR-038 (h=0.15)          211      53     25%        5        193
```

ADR-037 で**試行が 370 → 226 件（-39%）、成功件数が 139 → 103 件（-26%）**。
率が 38% → 46% に上がったので改善と報告したが、レースで効くのは件数であり、
実際には悪化していた。直線の成功も 27 → 10 件と激減している。

`follow` への遷移自体が 357 → 219 件に減っている。車間を広げた結果、
**そもそも追い越しを検討する場面に入らなくなった**。

### なぜ車間の拡大が試行を減らすか

`FollowPathState` の追い越し判定は
`forward_vehicle_distance <= FORWARD_FOLLOW_DISTANCE_M (5.0 m)` の内側でしか走らない。
旧設定の目標車間は中心間 2.5 m でこのゲートの十分内側だったが、
ADR-037 の h=0.25 では 4.24 m とゲート境界まで下がり、
V2X のノイズも重なって圏外に出る時間が増えた。

### ADR-037 の判断根拠自体が同じ誤りだった

ADR-037 は「詰めるほど追い越しに失敗する」として、突入時の中心間距離ごとの
**成功率**（0-3 m で 24%、3-4 m で 42%）を根拠にしていた。
しかし 0-3 m 帯は試行が 29 件しかなく、母数の少ない帯の率を比較していた。
帯ごとの率ではなく、設定変更前後の**総成功件数**で評価すべきだった。

## 決定事項

### 1. 目標車間を幅条件つきの積極的な値に戻す

```python
        d_des = (
            D0_M                                                  # 0.9 m
            if ctx.min_forward_overtake_width >= MIN_OVERTAKE_WIDTH_M
            else FOLLOW_TARGET_DISTANCE_M                         # 1.2 m
        )
```

`FOLLOW_TIME_HEADWAY_SEC` と `follow_target_gap_m()`、および ROS パラメータ
`follow_time_headway_sec` を削除する。
**追い越せる幅があるときに詰めて助走を作るのは、競技として正しい挙動だった。**

### 2. 停止距離は残す。ただし目標車間とのマージンを確保する

`FOLLOW_STOP_DISTANCE_M` を **0.8 → 0.5 m**。

停止距離ルール（`gap <= FOLLOW_STOP_DISTANCE_M` で `v_cmd = 0`）は、車間を広げずに
追突だけを止められる。追突対策として実効があるのはこちらで、目標車間の拡大ではない。

ただし目標 `D0_M = 0.9` に対して閾値 0.8 では差が 0.1 m しかなく、平衡点で
全制動と解除を往復する。0.5 m なら 0.4 m のマージンが取れる。

### 3. 結果として `naito_v1.3.4` からの差分は 3 点だけになる

| 変更 | 由来 |
|---|---|
| `FOLLOW_STOP_DISTANCE_M` 0.8 → 0.5 | 本 ADR |
| 追従 PD に停止距離ルールを追加 | ADR-037 決定 2（維持） |
| 停止・徐行の先行車を内側 veto の例外に | ADR-039 |

**車間は v1.3.4 と同一に戻っている。** 追い越しの試行回数・成功件数は
v1.3.4 相当（370 試行 / 139 成功）に戻る見込み。

## この一連の失敗から引くべき評価基準

今後、追い越し系の変更は次の順で評価する。率は最後に見る。

1. **成功件数**（レースで効くのはこれ）
2. **試行回数**（減っていれば、率が上がっても改善ではない）
3. 停止に伴う時間ロス（recovery 件数 × 滞在時間、本番なら最遅周）
4. 成功率（1・2 を確認した後の補助指標）

## 未解決事項

1. **突入の 37〜41% は自車より速い相手に仕掛けている**（本番実測、相対速度が負）。
   成功率 17〜18%。`safe_width` は `is_slow_leader`（絶対速度 25 km/h 以下）しか
   見ておらず相対速度ゲートが無い。`is_ttc_close` は
   `forward_vehicle_gap == 0.0` により恒真（ADR-027 から継続）。**次の最有力候補。**
   ただし本 ADR の教訓どおり、試行を減らす方向の変更は成功件数で検証すること。
2. 本番の直線成功率が 11〜12%（dev は 29〜46%）。相手の速度域の違い。
3. コーナーの `narrow` 中断は突入時の観測量では弁別できていない。
   `_exit` ログへの将来幅・要求幅の追加が先。
4. 本番 run A の 28.2 s 停止（前方車なし）は壁での停止。
   ヘアピンに速度上限が掛かっていない件（ADR-033 決定 2）が残る。
5. `is_colliding` が一度も立たず、**追突回数を直接計測する手段が無い**。

## 検証
