# ADR-003: 周囲に車両がいない状況での誤った FollowState 遷移の抑止 (False FollowState Elimination)

## ステータス
承認待ち (Proposed)

## コンテキスト
単独走行中または周囲に車両がいない状況において、`FollowPathState`（Pure Pursuit 走行）から `FollowState`（先行車追従 MPC）への誤遷移が頻発する事象が観測された。

### 原因の分析
1. **LiDAR 前方クリアランスによる壁誤検知**:
   カーブ・シケイン手前において、LiDAR 前方コーン（±30度）がコース外壁やタイヤバリアを捉え、`lidar_forward_clearance < 15.0m` となって前方車両として誤認されていた。
2. **V2X 前方車両判定の過大範囲とコース非考慮**:
   `MAX_DIST = 15.0m`、`HALF_ANGLE = ±45.0deg`（開き角 90 度）という広角扇形かつユークリッド距離のみで判定していたため、ヘアピンコーナーの隣レーンや対向コースを走る他車を「自車直前の先行車」と誤認していた。

## 決定事項

### 1. V2X 前方車両検出の厳格化（横方向ゲート + 角度・距離の絞り込み）
自車座標系（進行方向 $x_{\text{rel}}$、横方向 $y_{\text{rel}}$）を導入し、以下の複合条件を満たす場合のみ「同一レーンの先行車両」として認識する：
- 前方距離: $0.5\text{m} \le x_{\text{rel}} \le 10.0\text{m}$（従来の 15m から 10m に短縮）
- 横方向オフセット: $|y_{\text{rel}}| \le 2.0\text{m}$（自車の走行幅内に限定し、隣接レーン・対向車を完全排除）
- 方位角差: $|\text{angle}| \le 20.0^\circ$（従来の ±45度から ±20度に絞り込み）

### 2. 先行車両検知における LiDAR と V2X の役割の適正分離
- **先行車追従 (`FollowState`) への遷移トリガー**: 車両位置を正確に特定できる V2X 車両情報（`forward_vehicle_distance`）に一本化し、壁を検知する LiDAR クリアランス単独での誤遷移を根絶する。
- **LiDAR の役割**: 追い越し時の左右空間の空き幅（`overtake_width_left / right`）の計測に専念させる。

## 影響と効果
- 単独走行時やカーブ進入時にコース壁を検知して不意に減速・追従モードに落ちる現象が 100% 解消される。
- ヘアピンやつづら折り区間で隣のレーンにいる他車を誤検知して速度低下する問題が解消される。
- 先行車両の直後に接近した時のみ、確実に `FollowState` または `OvertakeState` へ遷移する。
