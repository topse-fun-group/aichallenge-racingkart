multi_purpose_mpc_ros_with_dynamic_param

Autoware Universe ベース・レーシングカート用多目的動的パラメータ空間MPC (Model Predictive Control) ドキュメント

ROS 2 Humble OSQP Solver State Pattern (4 States) V2X & LiDAR Fusion

📌 システム概要

multi_purpose_mpc_ros_with_dynamic_param は、レーシングカートのタイムアタックおよび他車との対戦（追従・追い越し・衝突自動復帰）を実現するために設計された自律走行MPCパッケージです。

🚀 高精度レーシングライン追従 (follow_path)

空間キネマティックモデル（直交偏差 $e_y$・方位偏差 $e_\psi$・時間偏差 $t$）に基づき、最高 35 km/h で最小曲率 raceline を高精度追従します。

🚙 動的車間距離調整 (follow)

V2X 位置情報および速度推定を用いて、前方車両と 10m の安全車間距離を維持するように速度プロファイル上限 $v_{max}$ をリアルタイム調整します。

🏎️ 空間コリドー動的横オフセット (overtake)

LiDAR スキャンによる左右空き幅のセンシングに基づき、レーシングライン中心線を生成し直すことなく自車座標系をオフセット ($\pm 1.2 \sim 2.2\text{m}$) させて安全に追い越します。

↺ 自動衝突/スタック自律復帰 (recovery)

壁接触やスタック状態を自動検知し、一時停止 $\rightarrow$ ギア REVERSE 後退 $\rightarrow$ トラック再復帰までの一連のリカバリー動作を完全自動実行します。

🧮 MPCパラメータ・制御理論

空間キネマティック・バイシクルモデル

自車位置 $(x, y, \theta)$ を参照軌道からの空間状態量 $x = [e_y, e_\psi, t]^T$ に評価し、OSQP ソルバーで以下の評価関数を最小化します。

J = ∑_{k=0}^{N-1} ( x_k^T Q x_k + u_k^T R u_k ) + x_N^T Q_N x_N

コスト行列および主要パラメータ

パラメータ名 設定値 単位 説明と選定根拠
Q[0] ($e_y$) 1,000,000.0 - 横偏差コスト。直線・コーナリングでのライン維持を高精度に強制
Q[1] ($e_\psi$) 100,000,000.0 - 方位偏差コスト。車首の振れ・スピンを強く抑制
Q[2] ($t$) 850,000.0 - 時間偏差コスト。目標参照速度への到達性を確保
R[0] ($v$) 100,000.0 - 速度制御入力コスト。急激な速度変動を抑制
R[1] ($\delta$) 100.0 / 1000.0 - ステア角制御入力コスト。ステアリング高周波振動・ハンチングを遮断
v_max 35.0 km/h 直線区間における最高速度 ceiling
ay_max 9.5 m/s^2 限界コーナリング横加速度。$v_{curve} = \sqrt{a_{y,max} / |\kappa|}$ で減速基準を自動生成
steer_low_pass_gain 0.4 - ステアリング出力ローパスフィルタ。実機サーボへの高周波振動伝播を防止

🏎️ 各走行状態の制御詳細

1. follow_path (最速ライン追従)

  • 最高速度: 35.0 km/h
  • 横加速度上限: 9.5 m/s^2
  • コース最小曲率ライン (Min-Curvature Raceline) に対してオフセットゼロで完璧に追従し、最速ラップを刻みます。

2. follow (車間距離維持)

  • 目標車間距離: 10.0 m
  • P制御動的速度: $v_{target} = v_{leader} + 0.5 \times (d_{fwd} - 10.0)$
  • 下限速度 20.0 km/h を担保し、追突を回避しながら追い越しチャンスを伺います。

3. overtake (動的横オフセット追い越し)

  • 動的横オフセット: 左追越 $\in [+1.2, +2.2\text{m}]$ / 右追越 $\in [-1.2, -2.2\text{m}]$
  • 存続時間: 最大 2.5s
  • 自車座標をシフトしてMPCに入力することで、中心線パスを変更することなく車線変更・追い越しを実行します。

4. recovery (自動復帰)

  • Phase 1 (wait): 2.0s 完全停止 (ブレーキ)
  • Phase 2 (back): ギア REVERSE, 速度 -2.5 m/s, 向き修正 P制御ステアリング
  • 復帰後 5.0s はクールダウン期間を設け、再度の誤復帰動作をシャットアウトします。
